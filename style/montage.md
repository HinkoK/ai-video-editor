# Стиль монтажа: стартовый

Бережная чистка. Отступать — только по слову автора. Свой стиль —
docs/STYLE_GUIDE.md.

## 1. Что уходит, что остаётся

- Дубли: остаётся лучший — полнее мысль, без оговорок, яснее (как в общем
  регламенте, «Дубли»).
- Ложные старты и оговорки с поправкой — уходят, остаётся исправленное.
- Технические паузы, подготовка записи, начало и конец записи — уходят.
- Ожидание результата — сокращается честно, с пометкой «ожидание сокращено».
- Кашель и звуки без слов — уходят (`list_noises` после чистки).
- Не трогать: ошибки в демонстрации и их исправление, ручные шаги, вдох и
  акцент. Порядок кусков не меняется.

## 2. Темп

- Границы и запас тишины у речи ставит сервер — свои числа не задаём.
- Паузы внутри фраз не сокращаем.

## 3. Кадр

- Раскладка — та, что выбрана в проекте. Участки кадра (`set_shot`) — только
  по просьбе автора.

## 4. Звук

- Звук ролика и громкость — как выбрано в проекте.

## 5. Главы

- По смысловым частям ролика, название — коротко и по сути.
