# Стиль автора

Правила, по которым Claude монтирует ролики этого автора. Инструмент
`editing_playbook` отдаёт Claude общий регламент редактора и следом файлы
отсюда:

- `montage.md` — что вырезать, темп, кадр, звук, главы;
- `motion.md` — движение камеры и графика.

Здесь лежит стартовый стиль: бережная чистка, без графики и движения. Свой
стиль — по [docs/STYLE_GUIDE.md](../docs/STYLE_GUIDE.md). Другая папка стиля —
переменная `LONGFORM_STYLE=<папка>` при запуске Claude.
