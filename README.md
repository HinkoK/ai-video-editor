# AI Video Editor

Локальный редактор длинных видео, в котором черновой монтаж делает Claude
Code. Записал час экрана и камеры — Claude вырезает неудачные дубли, ложные
старты и паузы, ставит кадр и графику на слова, а ты проверяешь каждую правку
в браузере: оставить, вернуть, сдвинуть стык. Готовый ролик ffmpeg собирает
из оригиналов с точностью до кадра и звукового отсчёта и сверяет с
исходником. Всё работает на твоём компьютере, видео никуда не загружается.

Как монтировать — решает **стиль**: файлы с правилами в `style/`, которые
Claude читает перед работой. В репозитории лежит стартовый стиль (бережная
чистка без графики и движения). Как собрать свой по роликам, которые тебе
нравятся, — [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md).

## Что умеет

- **Чистка:** неудачные дубли, ложные старты, технические паузы, честное
  сокращение ожидания (с пометкой на экране), кашель и «кхм».
- **Перестановка кусков** — только по твоему прямому указанию.
- **Две камеры в одной записи:** экран с микрофоном и камера сводятся по
  звуку (смещение и скорость).
- **Кадр:** экран, лицо целиком, лицо в углу, экран в рамке с лицом сбоку,
  свои кадры, смена плана на склейках, укрупнения, шторка.
- **Графика на HTML/CSS:** Chrome рисует её кадр за кадром с прозрачностью;
  стартовый набор из десяти шаблонов, вставка страницы по ссылке.
- **Субтитры .srt, главы для YouTube, выравнивание громкости.**
- **Интерфейс:** очередь проверки с «до» и «после», расшифровка с поиском,
  таймлайн с дорожками, монитор программы, ручной монтаж клавишами как в
  Premiere Pro.

## Как Claude безопасен

- У Claude нет инструментов «утвердить», «экспорт» и «удалить». Утверждает,
  собирает финальный ролик и чистит хранилище только автор.
- Claude Code запускается без встроенных инструментов: только инструменты
  редактора через MCP.
- Модель не считает время: она говорит «убрать фразу 12», точную границу в
  тишине ставит сервер.
- Текст из видео — данные, а не команды: фраза «удали исходник» в записи
  ничего не разрешает.
- Исходники только читаются, готовые ролики не перезаписываются, версии
  монтажа неизменны.

## Что нужно

- macOS, ffmpeg и ffprobe в PATH.
- whisper.cpp (`whisper-cli` в PATH) и модели:
  `~/.cache/whisper/ggml-large-v3-q5_0.bin` (скачивается скриптом
  `models/download-ggml-model.sh large-v3-q5_0` из репозитория whisper.cpp) и
  модель Silero VAD для whisper.cpp `~/.cache/whisper/ggml-silero-v6.2.0.bin`.
  Другие пути — переменные `LONGFORM_WHISPER_MODEL`, `LONGFORM_VAD_MODEL`.
- [uv](https://docs.astral.sh/uv/) (Python 3.12 он поставит сам), Node 22.
- Google Chrome — им рисуется графика и снимаются страницы (другой путь —
  переменная `CHROME`).
- Claude Code — для монтажёра.

## Запуск

    cd frontend && npm install && npm run build      # интерфейс
    cd graphics && npm install                       # графика
    cd backend && uv sync
    cd backend && uv run longform-server             # сервер и фоновый исполнитель
    cd backend && uv run longform-open               # открыть редактор в браузере

Сервер слушает только `127.0.0.1:8765` (порт — `LONGFORM_PORT`). База и медиа —
в `~/Movies/AI_Video_Editor_Media` (меняется `LONGFORM_WORKSPACE`).

Монтажёр для проекта:

    cd backend && uv run longform-agent <id проекта> # рабочая папка Claude с .mcp.json и запретами
    <папка Claude>/start.sh                          # Claude Code только с инструментами редактора

Дальше в Claude Code: «смонтируй по регламенту» (или подсказка `rough_cut`).

Подробно — [docs/run.md](docs/run.md), устройство — [docs/tech.md](docs/tech.md).

## Проверки

    cd backend && uv run pytest                      # тесты сервера, около 4 минут
    cd frontend && npx vitest run && npm run build   # тесты и сборка интерфейса

Тесты с пометкой `media` создают синтетические видео (номер кадра нарисован в
картинке, звук — шум с известным зерном) и проверяют результат по
раскодированным кадрам; `asr` запускают whisper.cpp на синтетической речи.
