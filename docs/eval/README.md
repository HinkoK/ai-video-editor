# Оценка работы Claude на твоей записи (этап 5)

Без этого «Claude хорошо монтирует» — мнение. Здесь — как превратить его в
проверяемый факт на твоём материале.

## Что нужно от тебя

1. **Запись**, лучше 10–20 минут: камера и экран, как ты обычно снимаешь, с
   настоящими оговорками и повторами. Не правь её заранее.
2. **Разметка** по шаблону [labels-template.json](labels-template.json),
   примерно 20–30 минут. Время — как в плеере, по исходнику:
   - `required` — мысли и оговорки, которые нельзя потерять (отрицания,
     условия, цены, реальные результаты на экране);
   - `good_takes` — дубли, которые должны остаться;
   - `bad_takes` — то, что должно уйти: неудачные дубли, ложные старты;
   - `joints_to_check` — места, где ты ждёшь трудный стык.
   Размечай до того, как увидишь предложения Claude: иначе разметка
   подстроится под них.

## Как прогнать

```
cd backend
uv run longform-server                      # в отдельном окне
# подключить файлы, расшифровать (через интерфейс или API)
uv run longform-agent <id проекта>          # рабочая папка Claude
<папка>/start.sh                            # обычный Claude Code, только инструменты редактора
```

В Claude Code: «Сделай черновой монтаж по регламенту». Первый запуск в папке
спросит доверие к ней — подтверди один раз.

Без диалога, с журналом для оценки стоимости:

```
<папка>/start.sh -p --allowedTools "mcp__longform__*" --permission-prompts none \
  --max-budget-usd 2 --output-format stream-json --verbose \
  "Сделай черновой монтаж по регламенту" > прогон.jsonl
```

Потом проверь предложения в очереди стыков и прими или отклони их. Оценка:

```
uv run python scripts/eval_agent.py --project <id> --labels разметка.json --run-log прогон.jsonl
```

## Как читать отчёт

- `blocker: true` — Claude задел обязательное место. Это провал, сколько бы
  дублей он ни нашёл.
- `as_proposed` — что было бы, прими ты всё; `after_review` — после твоих
  решений. Разница — то, что поймала твоя проверка.
- `excluded_by_review` — что ты отклонил. Это и есть материал для правки
  регламента.
- `risk_flags` — сколько правок ушло на поштучную проверку и почему.
- `run` — стоимость, ходы, время. `non_editor_tools` должен быть пустым.

Прогон на синтетическом уроке (голос macOS, не твой): 2 из 2 плохих
дублей найдены, обязательное не задето, 14 ходов, $0,48.

Любая смена модели, регламента, Whisper или склейки — повторный прогон на
той же разметке. Разметку не подправлять под удачный результат.
