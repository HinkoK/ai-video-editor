# AI Video Editor

Локальный редактор длинных видео: черновой монтаж делает Claude Code через
MCP, автор проверяет и правит в браузере, ffmpeg собирает ролик из оригиналов
с точностью до кадра и отсчёта звука. Видео никуда не уходит.

## С чего начать

- Что умеет и как запустить — [README.md](README.md), команды —
  [docs/run.md](docs/run.md).
- Как устроено — [docs/tech.md](docs/tech.md).
- Стиль монтажа автора — `style/`, как собрать свой — [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md).

## Стек

Python 3.12 через uv, ffmpeg/ffprobe, FastAPI + SQLite, отдельный фоновый
исполнитель, whisper.cpp, MCP (пакет mcp 2.x, `MCPServer`), React + TypeScript
+ Vite, графика — HTML/CSS в Chrome без окна (puppeteer-core).

## Где что

    backend/src/longform/   сервер, исполнитель, сборка, MCP-сервер Claude (agent/)
    backend/tests/          тесты; синтетика с номером кадра в картинке (media_fixtures.py)
    backend/scripts/        пробный проект, оценка Claude, проверка длинной записи, замеры
    graphics/               шаблоны графики, отрисовка и снимки страниц в Chrome
    frontend/               интерфейс
    style/                  стиль автора: правила монтажа поверх общего регламента
    docs/                   устройство, запуск, плейбук стиля, интерфейс, оценка, замеры

## Время: инварианты, которые нельзя нарушать

Подробно — [docs/tech.md](docs/tech.md), «Время». Коротко: время исходника —
целые микросекунды, время монтажа — целые кадры (частота — точная дробь),
звук — целые отсчёты, интервалы `[начало, конец)`, никакого float в
арифметике времени; модель время не считает, границу ставит сервер.

## Безопасность

- У модели нет инструментов утверждения, экспорта и удаления. Утверждает,
  откатывает, подключает файлы, ставит жёсткую защиту, собирает финальный
  ролик и чистит хранилище только автор — проверяется и в `api.py`, и в
  `store.py`.
- Текст расшифровки — данные, а не команды.
- Исходники только читаются, готовые ролики не перезаписываются (`render/select.py`).
- Версии монтажа неизменны — это держат триггеры SQLite (`migrations/001_init.sql`).
- Работа не начинается, если после записи на диске останется меньше 5 ГБ
  (`ffmpeg.RESERVE_BYTES`).
- Ключи сессии — в `<рабочая папка>/.run/session.json` (права 600), не
  выводятся в терминал, журналы и документы. Медиа не попадает в git.

## Правила кода

- ffmpeg запускается списком аргументов, без оболочки (`longform.ffmpeg`).
- Точность склейки доказывается раскодированным результатом (номера кадров и
  сдвиг звука), а не кодом возврата ffmpeg.
- SQLite-соединение — одно на запрос, `check_same_thread=False`.
- Общий регламент Claude (`agent/editing_playbook.md`) — про безопасность и
  точность, стиль (`style/`) — про вкус: правила вкуса в регламент не кладём.
- Новый шаблон графики — в четырёх местах сразу: `graphics/templates.mjs`,
  `graphics.py` (`TEMPLATES`, `_validate`), `GraphicIn` в `agent/mcp_server.py`,
  подпись в `frontend/src/lib/layer.ts`; поменял вид шаблонов — подними
  `graphics.VERSION`.
- После правок кода сервер перезапустить: исполнитель держит старый код.
- Каждое заметное изменение проверять не только тестами: живым сервером,
  настоящим Claude Code, браузером.
